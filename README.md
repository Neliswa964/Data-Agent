# Retail Sales Data Agent

## Project Overview
This project demonstrates the development of a Retail Sales Data Agent using Databricks. The agent analyzes a retail sales dataset and answers business questions about sales performance, customer behaviour, product categories, and sales trends.

## Project Objective
The objective of this project is to build an AI-powered data agent that helps business users make informed decisions using data-driven insights from the retail_sales_data dataset.

## Tools Used
- Databricks
- SQL
- GitHub
- Word

## Dataset
The dataset contains the following columns:
- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Project Steps
1. Uploaded the retail sales dataset.
2. Reviewed the dataset.
3. Prepared the retail_sales_data table.
4. Created the Retail Sales Data Agent.
5. Wrote custom agent instructions.
6. Tested the agent with 10 business questions.
7. Validated three responses.
8. Compiled the project documentation.
9. Published the project on GitHub.

## Sample Questions
- What is the total sales revenue?
- Which product category has the highest sales?
- Which gender spent the most?
- What is the average transaction value?
- Which month recorded the highest sales?

## Key Insights
- The data agent provides quick access to business insights.
- It supports decision-making using real retail sales data.
- It helps identify sales trends and customer purchasing patterns.

## Business Recommendations
- Keep enough stock of high-selling products.
- Promote products with low sales.
- Target marketing based on customer buying patterns.
- Monitor monthly sales trends.
- Use data to support business decisions.

## Conclusion
This project demonstrates how AI and data analytics can be combined to answer business questions efficiently. The Retail Sales Data Agent provides useful insights that help improve business decision-making.
